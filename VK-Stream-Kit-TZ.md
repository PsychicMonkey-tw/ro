# Техническое задание: VK Stream Kit

**Проект:** VK Stream Kit  
**Бренд:** Psychic Monkey (расширение экосистемы)  
**Версия документа:** 1.0  
**Дата:** 01.07.2026  
**Платформа:** VK Video Live + OBS Studio  

---

## 1. Общие сведения

### 1.1. Назначение документа

Настоящее ТЗ описывает требования к разработке веб-сервиса **VK Stream Kit** — единого кабинета для стримеров **VK Video Live**, объединяющего оформление канала, виджеты для OBS, алерты и интерактивные триггеры из чата.

### 1.2. Цель продукта

Дать VK-стримеру (особенно новичку) возможность за **10–15 минут**:
- авторизоваться через VK ID;
- выбрать оформление;
- получить готовые ссылки для OBS;
- выйти в эфир на VK Video Live с алертами и командами из чата.

### 1.3. Целевая аудитория

- начинающие стримеры VK Video Live (1–100 зрителей в пике);
- стримеры, переезжающие с Trovo / с мобильного эфира на OBS;
- подписчики сообщества Psychic Monkey;
- русскоязычные авторы, которым сложно собирать StreamElements + StreamDPS + MiniChat вручную.

### 1.4. Что НЕ входит в продукт (явные исключения)

- мини-приложение с заданиями, фестами, merge-играми (Monkey Fest);
- собственный сервис приёма донатов (используется интеграция с DonationAlerts);
- мультистрим на Twitch / YouTube / Kick (только VK Video Live в v1);
- полноценный аналог Streamer.bot;
- мобильное нативное приложение (только веб-кабинет + браузерные виджеты);
- каталог из 50+ виджетов на старте.

## 2. Анализ рынка и позиционирование

### 2.1. Конкуренты (фрагментированный рынок)

| Сервис | Сильные стороны | Слабые стороны для VK |
|--------|-----------------|------------------------|
| VK Video Live Studio | встроенные баллы, бот, ключи RTMP | нет OBS-оформления, нет алертов «из коробки» |
| streamSync | панель Twitch+VK, боты | нет оформления, нет алертов/триггеров OBS |
| StreamDPS | виджеты, триггеры из чата | нет единого VK-кабинета, нет оформления PM |
| MiniChat + Streamer.bot | алерты VK, автоматизация | сложная настройка, десктоп, не веб |
| DonationAlerts | донаты, алерты донатов | не заточен под VK Live целиком |
| StreamElements | оверлеи, бот (Twitch/YouTube) | нет поддержки VK чата и событий |

### 2.2. Уникальное торговое предложение (УТП)

**«Единственный русскоязычный кабинет: оформление Psychic Monkey + алерты + триггеры — только для VK Video Live»**

## 4. Нефункциональные требования

### 4.1. Производительность

- задержка от сообщения в чате до показа триггера: **≤ 2 сек** (при нормальной сети);
- виджеты OBS: первая отрисовка **≤ 3 сек**;
- кабинет: отклик страниц **≤ 1 сек** (без учёта VK OAuth).

### 4.2. Надёжность

- uptime целевой: **99%** (для MVP допустимо 95%);
- автопереподключение WebSocket у виджетов при обрыве;
- graceful degradation: если VK API недоступен — виджет показывает статус в кабинете, не ломает OBS.

### 4.3. Безопасность

- все URL только **HTTPS**;
- токены виджетов — неугадываемые (UUID v4, min 32 символа);
- секреты VK и DA только на сервере (env variables);
- rate limiting на API;
- CORS только для доменов виджетов и кабинета.

### 4.4. Совместимость

- **OBS Studio** 28+ (Browser Source);
- браузерный движок OBS (CEF): поддержка WebM, PNG, GIF, WebSocket;
- **VK Video Live** актуальная версия на момент разработки;
- разрешение стрима: 1920×1080 (основной), 1280×720 (допустимо).

### 4.5. Локализация

- интерфейс кабинета: **русский** (v1);
- сообщения об ошибках: русский;
- документация: русский.

## 5. Техническая архитектура

### 5.1. Общая схема

```
[Стример]
    │
    ├─ Браузер → Кабинет VK Stream Kit (React + VKUI)
    │                 │
    │                 ▼
    │            [Backend API]
    │                 │
    ├─ OBS Studio ← Browser Sources (overlay, alerts, triggers)
    │                 │
    │                 ▼
    │            [WebSocket Server]
    │                 │
    ▼                 ▼
[VК Video Live] ← [VK DevAPI / Chat events]
```

### 5.2. Рекомендуемый стек

| Компонент | Технология |
|-----------|------------|
| Frontend кабинета | React 18+ / Next.js или Vite + **VKUI** |
| Backend API | Node.js (NestJS) **или** Python (FastAPI) |
| WebSocket | Socket.io **или** native ws |
| БД | PostgreSQL 15+ |
| Кэш / очереди | Redis (опционально, для алертов) |
| Файлы (паки, звуки) | S3-совместимое хранилище или локальный volume |
| Reverse proxy | Nginx |
| Контейнеризация | Docker + docker-compose |
| SSL | Let's Encrypt (Certbot) |

### 5.3. Структура репозитория (рекомендация)

```
vk-stream-kit/
├── apps/
│   ├── web/          # кабинет
│   ├── api/          # REST + WebSocket
│   └── widgets/      # статика виджетов (или в web/public)
├── packages/
│   └── shared/       # типы, константы
├── assets/
│   └── packs/        # паки оформления PM
├── docs/
│   ├── obs-setup.md
│   └── vk-devapi.md
├── docker-compose.yml
└── README.md
```

### 5.4. Модель данных (основные сущности)

**users**
- id (uuid)
- vk_user_id (bigint, unique)
- vk_access_token, vk_refresh_token, expires_at
- created_at, updated_at

**channels**
- id (uuid)
- user_id (fk)
- vk_channel_id / blog_url
- channel_title
- is_live (bool)
- created_at

**widget_tokens**
- id (uuid)
- user_id (fk)
- token (unique, secret)
- type: overlay | alerts | triggers
- created_at

**user_settings**
- user_id (fk)
- pack_id (fk)
- alert_sound, alert_duration
- alert_templates (jsonb)
- trigger_commands (jsonb) — массив до 3 команд
- da_widget_url (nullable)

**packs**
- id (uuid)
- slug, title, description
- is_free (bool)
- assets_path
- preview_url
- sort_order

**alert_queue** (или Redis)
- id, user_id, type, payload, status, created_at

## 6. API (черновик эндпоинтов)

### 6.1. Auth
- `GET /api/auth/vk` — редирект на VK OAuth
- `GET /api/auth/vk/callback` — callback
- `POST /api/auth/logout`

### 6.2. User / Channel
- `GET /api/me` — профиль, статус привязки канала
- `POST /api/channel/connect` — привязка VK Live канала
- `GET /api/channel/status`

### 6.3. Packs
- `GET /api/packs` — список доступных паков
- `GET /api/packs/:slug/download` — ZIP

### 6.4. Settings
- `GET /api/settings`
- `PATCH /api/settings` — алерты, триггеры, выбранный пак

### 6.5. Widgets
- `GET /api/widgets/urls` — три ссылки для OBS
- `POST /api/widgets/test-alert` — тестовый алерт

### 6.6. WebSocket
- `WS /ws/widget?token={widget_token}` — канал событий для виджета

### 6.7. Webhooks (v1.1)
- `POST /api/webhooks/donationalerts`

## 7. Пользовательские сценарии (User Stories)

### US-01: Первый стрим
1. Пользователь заходит на сайт → «Войти через VK».
2. Разрешает доступ → попадает в кабинет.
3. Нажимает «Привязать канал VK Live».
4. Выбирает бесплатный пак → видит превью.
5. Копирует 3 ссылки → вставляет в OBS как Browser Source.
6. Вводит URL и ключ RTMP из VK Studio в OBS.
7. Нажимает «Тест алерта» → видит алерт в OBS.
8. Запускает стрим.

**Критерий успеха:** пользователь без помощи поддержки выходит в эфир с оверлеем и тестовым алертом.

### US-02: Триггер из чата
1. Стример настраивает команду `!hype` → картинка из пака.
2. Зритель пишет `!hype` в чат VK.
3. На стриме появляется анимация/картинка.
4. Повторная команда в течение 30 сек игнорируется.

### US-03: Смена оформления
1. Стример меняет пак в кабинете.
2. Обновляет кэш Browser Source в OBS (или автообновление).
3. Новый стиль применяется без смены URL.

## 8. Инструкция для OBS (контент для кабинета)

### 8.1. Настройка RTMP VK Video Live

1. Открыть [live.vkvideo.ru](https://live.vkvideo.ru) → **Студия** → **Ключи и виджеты**.
2. Скопировать **URL сервера** и **ключ трансляции**.
3. OBS → **Файл → Настройки → Трансляция**.
4. Сервис: **Настраиваемый**.
5. Вставить URL и ключ → **Применить**.

### 8.2. Добавление виджетов VK Stream Kit

1. OBS → **Источники** → **+** → **Браузер**.
2. Создать три источника:
   - `PM — Оверлей` → URL из кабинета
   - `PM — Алерты` → URL из кабинета
   - `PM — Триггеры` → URL из кабинета
3. Ширина: **1920**, высота: **1080** (для полноэкранных триггеров).
4. Для оверлея: расположить рамку вебки и чат по превью пака.
5. Порядок слоёв: игра → вебка → оверлей → алерты/триггеры (сверху).

### 8.3. Запуск

1. **Начать трансляцию** в OBS.
2. В VK Studio нажать **Опубликовать** (если требуется).
3. Проверить тестовый алерт из кабинета.

| Сложность onboarding OBS для новичков | Высокая | видео-гайд, .json сцены, тест-алерт |
| Конкуренция streamSync / StreamDPS | Средняя | фокус только VK + оформление PM |
| Нагрузка на VPS при росте | Низкая (старт) | Redis, горизонтальное масштабирование ws |
