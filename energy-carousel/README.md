# Карусель Instagram: энергия через питание

Готовый превью-набор из 4 слайдов (формат **4:5**, как в ленте Instagram) под тексты про перенастройку питания и бесплатные диагностики.

## Как открыть

Откройте `energy-carousel/index.html` в браузере или поднимите локальный сервер из корня репозитория:

```bash
python3 -m http.server 8080
```

Затем перейдите на `http://localhost:8080/energy-carousel/`.

## Слайды

1. **Крючок** — вопрос про 100% энергии (место под ваше фото активного дня).
2. **Боль** — имитация сообщения «сил нет…» + тезис про срывы от жёстких ограничений.
3. **Подход** — сытость и комфорт, без таблеток; еда / сон / движение.
4. **CTA** — 5 бесплатных 15‑минутных диагностик, слово **ЭНЕРГИЯ** в директ.

## Экспорт в картинки

1. Откройте `index.html?export=1` — слайд рендерится в размере **1080×1350**.
2. Листайте стрелками или кнопками 1–4.
3. Сделайте скриншот области слайда (или используйте инструмент захвата окна).
4. На слайде 1 замените декоративный фон своим фото: положите изображение в `.hero-photo` через CSS `background-image`.

## Навигация

- Кнопки 1–4 в шапке
- Стрелки по бокам
- Клавиши ← →
- Свайп на мобильном
